# Music tracks

Drop your royalty-free MP3s in this folder, named exactly:

- track-1.mp3
- track-2.mp3
- track-3.mp3

(Add more by copying the pattern — see the `tracks` array near the bottom of
`index.html`, and add a matching `{ title, artist, src }` entry for each new file.)

Then open `index.html` and edit the `title` / `artist` fields in that same
`tracks` array so the player shows real song names instead of the placeholders.

Good royalty-free sources: Pixabay Music, Free Music Archive, YouTube Audio
Library, Chosic — just confirm each track's license allows the use you have in mind.
